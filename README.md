# Handasa Revenue Engine
## محرك هانداسا لتحليلات الإيرادات
تقارير قراءة فقط لتحليل إيرادات الشبكة ومؤشرات الحوكمة دون تحويل أموال أو توقيع معاملات.

محرك تقارير قراءة فقط لتحليل رقم آخر كتلة وإخراج **تقدير توضيحي** اختياري. لا يثبت هذا المشروع ملكية محفظة أو سلطة حوكمة أو استحقاق عوائد، ولا يوقّع أو يرسل أو يحوّل أي معاملة.

## المتغيرات

ضع هذه القيم العامة في GitHub Actions Variables:

- `OBSERVED_VOLUME_USD` — قيمة حجم مراقبة مقدمة من مصدر موثوق؛ لا يدّعي السكربت أنه يستخرج حجم USDT من `eth_blockNumber`.
- `FEE_PERCENTAGE` — نسبة تقديرية للتقارير فقط، مثل `0.005`.

ضع هذه القيم الحساسة في GitHub Actions Secrets:

- `NETWORK_RPC_URL` — رابط RPC للقراءة فقط.
- `DISCORD_WEBHOOK` — Webhook للتقرير الاختياري.

ضع هذه القيم العامة في **Actions Variables** لمراقبة الإيداعات فقط:

- `DEPOSIT_WALLET_ADDRESS` — عنوان عام لمحفظة الاستقبال التي تريد مراقبتها، وليس مفتاحًا خاصًا.
- `USDT_CONTRACT_ADDRESS` — عنوان عقد USDT على الشبكة المستهدفة.
- `USDT_DECIMALS` — غالبًا `6` لـ USDT، ويجب التحقق منه حسب الشبكة.
- `SCAN_BLOCKS` — عدد الكتل الأخيرة للفحص، مثل `5`.
- `EXPLORER_TX_URL` — قالب رابط المعاملة، مثل `https://etherscan.io/tx/{tx_hash}`.

لا تضع مفاتيح خاصة أو عبارات استرداد أو عناوين محافظ حساسة في الكود أو السجلات أو Discord.

## التشغيل

```bash
export NETWORK_RPC_URL="https://your-read-only-rpc.example"
export OBSERVED_VOLUME_USD="0"
export FEE_PERCENTAGE="0.005"
python revenue_engine.py
```

## مراقبة الإيداعات

يشغّل `deposit_monitor.py` قراءة `Transfer` logs لعقد USDT إلى العنوان العام المكوّن. عند رصد سجل مؤكد، يرسل Discord Embed بالنص:

`🔔 تم إيداع في المحفظة الفورية: [المبلغ] USDT بنجاح!`

مع رقم الكتلة ورابط المعاملة. هذا **إثبات رصد على السلسلة فقط**؛ السكربت لا يحوّل الأرباح إلى المحفظة ولا يوقّع أو يبث أي معاملة.

تقرأ `dashboard.py` ملف `data/deposits.jsonl` وتعرض مجموع الإيداعات المرصودة. لتشغيلها:

```bash
pip install -r requirements-dashboard.txt
streamlit run dashboard.py
```

## الأتمتة

يشغّل `.github/workflows/revenue_cron.yml` اختبارات الجودة ثم المحرك كل 5 دقائق أو يدويًا. GitHub Actions قد يؤخر الجدولة قليلًا بسبب ازدحام الخدمة.

## ملاحظة مهمة

النسخة الأصلية المرسلة في الطلب احتوت على بيانات افتراضية وادعاء حوكمة غير قابل للتحقق وعنوان محفظة داخل الكود. تم استبدالها هنا بحساب تقديري معلَّم بوضوح ووضع قراءة فقط. لا توجد وظيفة Automatic Profit Routing لأن نقل الأصول يتطلب توقيعًا وموافقة خارجية من محفظة باردة أو Safe متعدد التوقيعات.
